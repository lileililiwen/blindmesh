# Requirement traceability

Outcome: Publish budget-backed unified testing tasks. Every scenario of the change is covered by a named test that asserts its own observable result. The tests of the scenarios use the prefix of their requirement, so the filter `FullyQualifiedName~TASK` and the browser filter `--grep TASK` find them. No scenario is waived by API-only evidence: every human-facing outcome has a browser journey.

The migration of the package is proved by `TASKTheMigrationAddsTheTablesOfThePackageAndKeepsTheRowsOfTheEarlierPackages`: the schema of the last accepted package is migrated forward, a row of the identity package survives it and the five tables of the package appear with the right indexes.
